python_automation
This project demonstrates basic Python OS automation using the built-in os module.

Features:
- Get current working directory
- Change directory
- List files and folders
- Create and remove directories
- Rename files and folders
- Check file existence
- Work with file paths
- Get file size
- Read environment variables
- Execute system commands
- Perform network ping operations

This project is intended for beginners learning Python automation and system administration.
